## Dependency notes

None of the 10 plans hard-depend on one another — each was deliberately scoped to be independently
executable and verifiable. Soft relationships worth knowing about when sequencing work:

- **002 (stored XSS) and 005 (token revocation) compound**: 002's impact analysis assumes a stolen
  token grants indefinite access (005's finding). Landing 005 first reduces 002's worst-case blast
  radius, but 002 is the more urgent fix (the live exploitation path) — do not delay 002 waiting on
  005.
- **006 and the "three migration directories" systemic issue**: 006 fixes the concrete drift found
  during this review; it does not fix the broader "no doc says which schema source is canonical"
  problem (that's a DX finding not yet turned into its own plan — see below). Whoever executes 006
  should not attempt to solve the broader doc gap as part of it (out of scope per 006's own Scope
  section).
- **004 and 005 both touch auth** but are independent: 004 is about password strength and
  throttling; 005 is about token lifetime and revocation. Either can land first.

## Findings not yet planned

The audit surfaced ~34 total findings beyond the 10 above. None are rejected as "not worth doing" —
they simply weren't in the first selected batch. Ask for plans on any of these in a future round;
they don't need re-auditing, the evidence is already gathered (see the conversation that produced
this directory, or re-run the `improve` skill's `reconcile` mode once the codebase has moved).
Listed roughly by leverage:

**Performance**
- Chat message bubbles unmemoized — every streaming update re-renders/re-parses the whole visible
  message list (`ChatWindowContent.tsx`, `MarkdownContent.tsx`).
- No code-splitting — single 1.88MB/550KB-gzip bundle, every window type loaded eagerly.
- Unoptimized background images (up to 2.64MB JPGs, no resize/lazy-load).
- Agent memory list does `select('*')` including full file content for a metadata-only view.
- MCP `search_messages`/`search_docs` run leading-wildcard `ILIKE` with no supporting index.

**Tech debt & architecture**
- God-file regrowth: `App.tsx`/`ChatWindowContent.tsx`/`AgentsWindowContent.tsx` all grew
  substantially since the last review instead of being decomposed further.
- `useMemoryFileComments` duplicates `useRealtimeComments` line-for-line.
- Neo-brutalist theme reaches into shadcn component internals via ~246 attribute selectors with no
  compiler-checked link to the components it themes.

**Dependencies**
- Electron `33.4.11`, ~10 majors behind current, well past its security-support window (large,
  staged migration).
- `shadcn` CLI shipped in `dependencies` not `devDependencies`, never imported.
- `@open-pets/client` installed, zero imports anywhere.
- `landing/` frozen on React 18/Tailwind 3/lucide 0.x vs. root's React 19/Tailwind 4/lucide 1.x,
  plus still-dual lockfile.
- `agent/agensis-cli` local `file:` dependency drifted from its installed copy (`npm ls` errors) —
  trivial, just needs `npm install` and a note about when that's required.

**DX & tooling**
- Onboarding `scripts/neon-push.sh` hardcodes an Apple-Silicon Homebrew path; README says React 18
  while `package.json` says 19.
- Three migration-of-truth locations with no doc naming the canonical one (systemic version of
  plan 006's concrete fix).
- ~8MB of test artifacts (`.agensis_uploads/`, `.playwright-mcp/`) committed to git, not gitignored.
- Env vars required for split Netlify+Fly deploys undocumented outside a code comment.
- No CLAUDE.md/AGENTS.md despite the repo shipping its own agent CLI + MCP server.
- `server/MCP.md` references a `list_mentions` tool that doesn't exist.

**Tests**
- Agent daemon CLI's job queue/reconnect state machine untested despite an explicit
  "unit-testable" header comment.
- Window-tiling/canvas-selection geometry math untested; helpers aren't even exported to test.
- `App.tsx`/`ChatWindowContent.tsx`/new memory-browser/task-mention features have zero coverage and
  no React component-test infrastructure exists to add any.
- `neoThemes.expand()` untested despite one already-reverted regression in the same function.

**Correctness**
- `useCanvasObjects`'s realtime UPDATE path has no self-filter or freshness guard (out-of-order
  writes can revert a newer canvas-object position under network jitter) — MED confidence, would
  benefit from characterization tests before fixing.

**Direction (product calls, not bugs — see the presented table for full context)**
- Notification settings are fully disconnected from behavior (all 5 toggles are no-ops).
- Activity feed/notifications are blind to MCP-agent-originated work and membership/role changes.
- MCP agents can full-text search chat messages; the human Command Palette cannot.

**Known residuals, re-confirmed unchanged (already tracked in `code-review-update.md`, not
duplicated here)**: M1 (`server/index.cjs` still a parallel security implementation, not on
`shared/backend-core.mjs`), H3 (legacy WS query-string token path still live for the daemon CLI),
H4 (rate limiter still in-memory/per-process), H5 (four UI ecosystems still all installed), 23 lint
warnings (flat vs. last review).
