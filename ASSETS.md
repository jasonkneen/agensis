# Asset inventory

Every image, icon, font and vendored binary asset that ships in this repository
or in a build produced from it, with what is actually known about where it came
from.

This file is an **engineering provenance audit, not a legal clearance**. It
records evidence found in the files themselves and in the dependency tree. Where
the evidence does not establish a right to redistribute, the entry says so
rather than assuming one.

Third-party *code* attribution lives in [NOTICE](./NOTICE). This file covers
media.

## Method

- Binary assets enumerated with `git ls-files` filtered to media extensions, so
  the list is of tracked files, not of whatever happens to be in the working
  tree.
- Each file scanned for embedded provenance: C2PA/JUMBF manifests, XMP, EXIF and
  PNG text chunks.
- Hashes are the first 16 hex characters of the file's SHA-256. Reproduce with:

  ```bash
  shasum -a 256 <path>
  ```

- Fonts are resolved from npm packages rather than committed, so they are
  inventoried by package (see [Fonts](#fonts)).

### Provenance, stated plainly

These are AI-generated images, and the embedded C2PA manifests say by which
tools: five from Google's image model, two from OpenAI's (`gpt-image 2.0`).
That is recorded here rather than stripped, because it is true and because a
reader inspecting the files will find it anyway.

**They were generated by the project owner, on the project owner's own
accounts.** Output produced that way belongs to the account holder under both
providers' terms, so these ship under this project's licence along with
everything else.

One note for anyone re-encoding them: the two OpenAI originals carry
`c2pa.watermarked.unbound`. An unbound watermark lives in the pixels rather than
the metadata container, so converting or stripping metadata does not remove it.
That is a property of the files, not a restriction.

## Fonts

No font binaries are committed to this repository. Fonts are resolved from
`@fontsource` npm packages and bundled at build time by Vite, so the built site
does ship the font files.

All seven are licensed **SIL Open Font License 1.1 (OFL-1.1)**, which requires
that the copyright notice and licence accompany the Font Software wherever it is
distributed. Those notices are reproduced in [NOTICE](./NOTICE) — that file is
what discharges the obligation, and it must ship with any distribution of the
built site.

## Vendored runtime assets

| Path | Origin | Notes |
| --- | --- | --- |
| `public/scramjet-runtime/relay-transport.mjs` | Authored in this repository | The custom `BareTransport` implementation. MIT, same as the rest of the repo. |
| `public/scramjet-sw.js` | Authored in this repository | Service-worker entry point for the browser panel. |

The browser panel's rewriter itself (`scramjet.all.js`, `scramjet.sync.js`,
`scramjet.wasm.wasm`) is **not committed**. `vite.config.ts:60-62` copies it out
of `node_modules/@mercuryworkshop/scramjet/dist/` into the build output, so it
ships in built artifacts but not in the git tree.

Its licence sources disagree — the pinned 1.1.0 declares MIT in npm metadata,
its tarball ships AGPL-3.0 text, and upstream relicensed part-way through the 2.x
alphas. Since this project is itself AGPL-3.0, both readings are compatible and
no obligation arises that this project's licence does not already impose. The
full reasoning is in [NOTICE](./NOTICE), and the version is pinned exactly so a
routine bump cannot cross that boundary unnoticed.
