What you get

  • Same account and workspaces as agensis.io/app
  • Native window chrome (traffic lights on Mac)
  • Embedded browser panel that can open sites that refuse iframes
  • Microphone and camera prompts for huddles

Notes

  • macOS builds are currently unsigned — open via Right-click → Open the first time, or System Settings → Privacy & Security.
  • Windows SmartScreen may warn on first run for the same reason.
  • Installers are published from GitHub Releases.
  • The open-source agent daemon is separate: @agensis/agensis-agent.
